# SystemWeb

Angular authentication UI — reusable login and signup components built with Angular 19.

---

## Features

- **Login & Sign-up pages** — clean, production-ready authentication screens
- **Reusable `PrimaryInput` component** — configurable text/email/password input with icon support
- **`DefaultLoginLayout` component** — shared layout wrapper for all auth pages
- **SVG icon system** — email, password, logo, and illustration assets included
- **Standalone component architecture** — no NgModule boilerplate, fully tree-shakeable

---

## Tech Stack

| Layer | Technology |
|---|---|
| Language | TypeScript |
| Framework | Angular 19 |
| Styling | SCSS |
| Package manager | npm |

---

## Getting Started

### Prerequisites

- Node.js 18+
- Angular CLI: `npm install -g @angular/cli`

### Install & Run

```bash
npm install
ng serve
```

Open [http://localhost:4200](http://localhost:4200) in your browser.
